# DESIGN SYSTEM — промосайт «Всё рядом»

## Утверждённые логотипы

Пользователь выбрал вариант 1 как основной и вариант 3 как дополнительный. Готовые файлы и правила: [logos/README.md](logos/README.md). Вариант 2 остаётся неиспользуемым эскизом.

## 1. Общая идея

«Всё рядом» — тёплый, дружелюбный и современный локальный сервис аренды и совместного использования вещей.

Промосайт должен быть эмоциональнее самого приложения, но при этом оставаться минималистичным.

Главный принцип:

**Крупная идея + много воздуха + один сильный визуальный образ на секцию.**

Сайт не должен выглядеть как:
- тяжёлый маркетплейс;
- корпоративный SaaS;
- доска объявлений;
- интернет-магазин;
- перегруженный startup landing page.

По характеру:

**современный lifestyle-сервис + локальное сообщество + дружелюбный бренд.**

Основная формула:

> Интерфейс спокойный.  
> Бренд живой.  
> Жёлтый — акцент, а не фон всего сайта.

# 13. Hero

Hero задаёт дизайн всего сайта.

Desktop:

LEFT:
- небольшой kicker при необходимости;
- огромный H1;
- короткий текст;
- Primary CTA;
- Secondary CTA.

RIGHT:
- один большой lifestyle visual.

Пример:

Всё, что нужно,
рядом

Арендуй вещи у соседей и локальных сервисов —

[ Сдать вещь ]

Правила:

- минимум элементов;
- одно крупное фото;
- максимум один handwritten accent;
- максимум 1–2 декоративных элемента;
- без россыпи карточек вокруг человека;
- без множества UI-превью.

На каждой секции должен быть:

Это может быть:

- человек;
- предмет;
- телефон;
- коробка;
- инструмент;
- UI-фрагмент.

Не использовать одновременно много равнозначных визуалов.

# 19. Hover состояния

Primary button hover:

transform: translateY(-1px);

или:

transform: scale(1.01);

Transition:

150–200ms ease

Card hover:

transform: translateY(-3px);

Image hover:

transform: scale(1.02);

Не использовать агрессивные эффекты.

# 20. Shadows

Тени должны быть практически незаметными.

Пример:

0 8px 30px rgba(17, 17, 17, 0.04);

Лучше использовать:
- border;
- background separation;
- spacing;

вместо сильных теней.

# 30. Mobile Rules

Mobile — самостоятельная композиция.

Не переносить desktop буквально.

На мобильном:

- меньше декора;
- меньше вторичных CTA;
- меньше мелких текстов;
- один главный визуал;
- вертикальный поток;
- крупные touch targets.

Buttons:

минимум 48–52px высотой.

Основной CTA часто может занимать всю ширину.

---

# 31. Responsive Images

Desktop:

изображение может занимать 45–55% ширины секции.

Mobile:

изображение обычно занимает всю ширину контейнера.

Для lifestyle-фото:

border-radius:
24–32px

или использовать естественный cutout без рамки.

# 33. Что запрещено

Не использовать:

- много жёлтых секций подряд;
- чрезмерные градиенты;
- glassmorphism;
- тяжёлые тени;
- огромное количество карточек;
- десятки иконок;
- много мелких kicker labels;
- doodles в каждом свободном месте;
- более двух основных CTA на одном экране;
- длинные текстовые блоки;
- разные стили иллюстраций одновременно;
- чрезмерно мультяшную стилистику.

---

# 34. Проверка каждой секции

Перед реализацией каждой секции проверить:

Есть ли один сильный заголовок?

Есть ли короткое объяснение?

Есть ли один главный визуальный объект?

Есть ли максимум один основной CTA?

Есть ли максимум 1–2 декоративных акцента?

Достаточно ли пустого пространства?

Если элементов становится существенно больше — секцию нужно упрощать.
