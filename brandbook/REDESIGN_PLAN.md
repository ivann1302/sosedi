# План редизайна «Всё рядом»

> История предыдущего прохода редизайна. С 22 сентября 2026 года актуальная целевая структура главной задана в [HOME_PAGE_STRUCTURE.md](../HOME_PAGE_STRUCTURE.md). Для главной использовать её порядок и содержание. Статусы и проверки ниже относятся к прежней версии страницы.

Источник: `brandbook.md`, `brandbook.png`, утверждённые логотипы из `logos/README.md`.
Цель: перенести существующие секции промо-сайта в новую дизайн-систему, проходя сверху вниз. Сохраняем маршруты `/` и `/business`, назначение секций и статус «Скоро запуск».

## Текущий статус

Редизайн главной и страницы бизнеса завершён. Пользователь утвердил новую подборку людей (файлы `*-v2.webp`). Все секции проверены сверху вниз; результаты и превью приведены ниже.

## Общие решения

- Кремовый `#F7F4EA`, белые поверхности, текст `#111111`, жёлтый `#FFD400` для CTA и финального блока. Без оранжевых градиентов и тяжёлых теней.
- Основной логотип в шапке; круглый дополнительный в подвале и favicon.
- Локальные Montserrat (разрешённый fallback для Montserrat Rounded) и Caveat. Кириллица, WOFF2, минимум начертаний; без запросов к Google при сборке.
- Контейнер до 1360 px, мобильные поля 20 px, сетки от одной колонки, секции 72–96 px на мобильном и 110–160 px на десктопе.
- Один главный образ на секцию, максимум один рукописный акцент и 1–2 небольших декоративных элемента.
- Фотореалистичные статичные изображения и предметные иллюстрации; макеты интерфейса явно обозначаются как концепция.
- Не публиковать неподтверждённые рейтинги, число пользователей, реальные сделки или заявления о гарантиях. Числовую статистику заменить преимуществами.
- CTA до запуска ведут к описанию запуска или существующему контакту. Не добавлять OTP, формы без обработчика, ссылки на отсутствующие страницы и магазины.
- Server Components, HTML details для раскрывающихся элементов, CSS для оформления; убрать JS для появления контента, счётчиков, плавающих предметов и декоративного скролла.

## Страница для бизнеса: после главной

Сохранить последовательность: Hero → ценность платформы → преимущества → шаги подключения → продуктовый блок → FAQ → финальный CTA → общий Footer. Применить те же токены и фотографии, убрать неподтверждённую статистику. Предлагать обсудить участие в запуске по текущему email, не обещать уже работающий кабинет.

Статус страницы бизнеса: готово, проверено.

## Проверка готовности

- Проверить обе страницы на 320, 390, 768, 1024, 1440 px: переносы, изображения, отсутствие горизонтального переполнения, меню и FAQ.
- Проверить клавиатуру, focus-visible, один H1, alt, контраст, ссылки и наличие статичного контента без JS.
- Проверить загрузку локальных шрифтов и изображений, убрать неиспользуемые анимационные компоненты.
- Запустить `npm run lint`, `npm run build`, `git diff --check`.
- Сохранить скриншоты и заполнить итоговый статус этапов, указать оставшиеся ограничения.

## За пределами этого прохода

Полноценный блог со страницами статей, юридические тексты, backend, авторизация, магазинные ссылки и публикация приложения. Не придумывать юридические документы и не создавать фиктивные активные элементы ради макета.


## Итоговая проверка — 21 сентября 2026

- `npm run lint`, `npm run build`, `git diff --check` — успешно.
- Chromium: `/` и `/business` на 320, 390, 768, 1024 и 1440 px. Горизонтального переполнения, незагруженных изображений и ошибок JavaScript не обнаружено. На каждой странице один H1, description и Open Graph.
- Локальные Montserrat и Caveat загружаются. Меню и FAQ на обеих страницах открываются клавишей пробела при отключённом JavaScript.
- Все 12 уникальных внутренних ссылок и якорей проверены на финальной сборке, ошибок нет.
- На мобильном исправлен выход декоративного фона телефона за границы секции.
- Финальная браузерная проверка выполнена через standalone-сервер, соответствующий `next.config.ts`. Для такого режима использовать `npm run build:standalone` и `npm run start:standalone`: при тестовом `next start` наблюдалось зависание отдельных запросов оптимизации изображений.
- Фотографии с людьми сгенерированы и служат иллюстрациями; не представлены как реальные пользователи или отзывы. Промпты: [REDESIGN_IMAGES.md](REDESIGN_IMAGES.md).
- Montserrat используется как разрешённая замена Montserrat Rounded; точные файлы Rounded не найдены. Карта и экран приложения обозначены как концепции. Статус приложения — «Скоро запуск».
